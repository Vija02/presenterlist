Option to Auto Start items on the schedule at their own individually set time:-
Any items on the schedule can be given an Auto Start time – use the blue clock icon at the schedule or via Menu->Manage->Set Auto Start
One hour before an Auto Start item goes live, a countdown clock will appear on the Easyslides Main Window.
If easyslides is not live when the countdown reaches zero, easyslides will start a live show with the item.
If easyslides is live when the countdown reaches zero, the current live item will stop and the Auto Start item will go live.
Each item can only have one Auto Start time.
The maximum number of Auto Start items on a schedule is 200.
Export Schedules Packages will store Auto Start data (if any) and will therefore be available on another system after the Package is imported.
Easyslides regularly polls for Auto Start item times and therefore system performance may be impacted if you have set a large number of Auto Start items.
In v5.2 RC2 – 7th August 2023
For import/export of schedules there is now an option to convert infoscreens which have Bible passages back to Bible items during import.
How to export and import a schedule:
On your first computer create your schedule with all the items you require, eg. database items, Bible passages, slideshow, etc.
Use the export schedule option to generate an export zip file which contains all the necessary items to run a live show on a second computer with easyslides 5.2.
Copy the generated zip file to the second computer which has easyslides 5.2.
In easyslides 5.2 on your second computer use the import schedule option (or use drag and drop) to import in the zip file.
You will be prompted to confirm the import with an option to convert any Infoscreens with Bible passages back to Bible items.
On confirmation of import, a new schedule will be created which is a replica of the schedule and all items from your first computer.
You can now run your live show on your second computer.
Please note the following when using the export/import schedule function:
Database items and Bible passages on the schedule on the first computer are copied to the export zip files as infoscreens.
During import, if you had selected the option to convert Infoscreens with Bible passages back to Bible items, the names of the Bibles referenced in the infoscreens must exist on the import computer.
For example, if you had a passage from a Bible named “RSV”, the import computer must also have a Bible named “RSV”. If the named Bible is not present, the Infoscreen is not converted, and will remain as an Infoscreen on the schedule after import.
Exported schedules and imported items are stored in the folder EasyslidesData\Documents\Packages.
There might be slight layout differences on the second computer due to items being converted to infoscreens.
All items including media files, images, slide shows, etc referenced in the schedule on the first computer are copied to the export zip file. If you have a lot of large files, the export zip file can get very large and may take time to get generated.
Settings such as gap items, display panel, installed fonts, etc. are specific to each computer and therefore you will need to ensure the first and second computer have the same easyslides settings if you want to replicate the live show exactly.

New clock options:-
12 and 24 hours option for the three clocks in the output pane
Use the following in your text contents in the database or infoscreens, examples:-
[time] <– display the current time in 24 hour format
[time12] <– display the current time in 12 hour format
[time 19:00] <– display a countdown to the time 7:00 pm in the evening
[time 19:00 00:10] <– display a countdown to the time 7:00 pm in the evening and the countdown time will disappear after 10 seconds
[time 19:00 00:30 20:00] <– display a countdown to the time 7:00 pm in the evening and the countdown time will disappear after 30 seconds, and restart the countdown to the next 7pm after 20 minutes
[time 19:00] <– display a countdown to the time 7:pm in the evening. Default for display off is 10 seconds and display restart is 15 minutes.
Infoscreen examples demonstrating the new time options and formatting are available via Menu->Tools->Install Infoscreen Examples
If you are using multicast, the second computer receiving mulitcast must also run v5.2beta2 to be compatible with the new features.
