November 3, 2026
macOS

Feature updates
What’s New
Cloud - Prepare Sunday's playlist from home, make a change mid-service without interrupting the person running it, and get back to work on a new machine if a computer ever fails. Everything in a Cloud workspace stays in sync in near real-time, so every machine collaborating in it is always current, and your content is always backed up. Learn More
Text Animations - Create polished, animated lyric slides without ever leaving ProPresenter. Select a text object in the Editor and apply a Text Animation as a Build. From there, reveal the text by character, word, or line, set the pace and direction, and add continued motion for extra impact.
Stickers by ProContent - Add clear emphasis to sermon notes or vibrant energy to youth experiences with Stickers by ProContent. In the Editor, quickly search through a library of animated graphics you can drag and drop directly onto any slide.
Amazing Integration - The Amazing curriculum your church already pays for now imports straight into ProPresenter. Connect your APlay account, pick a playlist, and import it ready to run, with video and audio streaming and graphics saved to your machine.
Video & Audio Stream Actions - Play video or audio straight from an HLS stream URL, with no download and no file to manage. Paste the link and ProPresenter checks it right away, then plays it like any other media, live or on demand.
Export to ProDisplay - Quickly and easily export ProPresenter presentations to your connected ProDisplay account, and content is pushed automatically to your paired devices.
(macOS only) Support for macOS 27 Golden Gate.
What's Improved
Ability to Disable Screens - Need to keep a screen available, but don't want to waste resources rendering it? In Screen Configuration, you can now disable a screen so it can still be referenced, but doesn't take up any rendering resources.
Import PowerPoint Slides Without Background - Want to import a PowerPoint presentation, but don’t want to include the background? Now at time of import, you can choose whether the PowerPoint background is imported with the PowerPoint itself.
What's Changed:
(Windows) Fixes an issue where a newly signed in user could not complete onboarding.

TCP/IP Communication

Single Prop Mode
