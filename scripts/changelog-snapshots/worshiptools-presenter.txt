Presenter Change Log
2026.1.11
November 2, 2026
New/Improved
NDI: Added support for transparent backgrounds, eliminating the need for chroma keying.
Auto-Advance: Added the ability to cancel and resume.
Loop Connect: Added options to disable start and ending slides.
Loop Community imports now display track types.
Slides imported from folders now maintain their original order.
Media filters and tags are now preserved when using Media pickers.
Dragging Service Items now automatically scrolls the Service list.
Consolidated lyric sections in printed Services for a cleaner layout.
Made various UI/UX improvements.
Resolved
Countdown: Fixed an issue where clearing a countdown could cause it to continue into the next day.
Fixed an issue where default media scale settings were not consistently applied to new Service Items.
Fixed an issue where duplicating or deleting Slides while using a blank Slide could affect the wrong Slide.
2026.1.10
October 26, 2026
New/Improved
Loop Connect: Added the ability to override and resume a session.
Loop Connect: Improved support for empty lyrics
Stage Display: add option to show ChordPro as numbers
SongSelect Lyric Videos are now supported when bulk-applying transition times.
Countdowns: Added an option to continue counting past zero.
Added separate transition times for foreground and background content.
Improved performance when displaying Slides.
Made various UI/UX improvements.
Resolved
Resolve issue causing the Main Audience Output to show as a small window if Display is not connected
Fixed an issue that prevented the Media page from loading when media tags were not present.
Improved consistency of section hotkey availability across songs.
Improved synchronization of original PowerPoint documents.
Fixed an issue where importing multiple files requiring conversion would not convert the entire batch.
Fixed an issue where sorting songs by key could cause entries to disappear from the list.
